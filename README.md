<h1 align="center">Rhythm</h1>

<p align="center">Открытый шаблон для планирования уровня активности по дням.</p>

## Зачем

Rhythm — это личный журнал регулярности в обычном Git-репозитории. Для каждой даты можно задать уровень от `0` до `15`: пустой день, одна отметка или более заметный день. Workflow сохраняет каждую отметку в `public/data/checkins.json` и создаёт соответствующее число коммитов.

Шаблон можно поставить в личный публичный репозиторий на GitHub, GitVerse или на обе платформы сразу.

> Платформы сами решают, засчитать ли коммит в карту активности. Чтобы он мог быть засчитан, используйте публичный репозиторий и email, подтверждённый в вашем профиле GitHub или GitVerse.

## Что делает

- работает бессрочно — после декабря 2026 и любого другого года;
- даёт выбрать уровень активности `0–15` для любой отдельной даты;
- не создаёт больше коммитов, чем задано в плане;
- хранит всю историю в одном читаемом JSON-файле;
- умеет запускаться вручную для проверки;
- по умолчанию живёт в учебном ритме: пн–пт в 00:05 по Екатеринбургу и одно воскресенье раз в две недели.

## Установка на GitHub

1. Нажмите **Use this template** или создайте новый публичный репозиторий и скопируйте в него содержимое этого проекта.
2. Откройте **Settings → Actions → General** и разрешите workflow запись: **Read and write permissions**.
3. В **Settings → Secrets and variables → Actions** добавьте два секрета:

| Секрет | Значение |
| --- | --- |
| `COMMIT_AUTHOR_NAME` | ваш логин или имя на GitHub |
| `COMMIT_AUTHOR_EMAIL` | email, подтверждённый в профиле GitHub |
| `TELEGRAM_BOT_TOKEN` | необязательно: токен Telegram-бота от BotFather |
| `TELEGRAM_CHAT_ID` | необязательно: ID чата для уведомлений |

4. Откройте вкладку **Actions**, выберите `Rhythm check-in` и нажмите **Run workflow**. Это проверит, что всё подключено.

Если добавить оба Telegram-секрета, после каждого успешного запуска с новыми коммитами бот пришлёт сообщение с датой и числом добавленных коммитов.

## Установка на GitVerse

1. Создайте публичный репозиторий и загрузите в него содержимое этого проекта.
2. В **Настройки → Секреты и переменные** добавьте те же `COMMIT_AUTHOR_NAME` и `COMMIT_AUTHOR_EMAIL`.
3. Откройте **CI/CD → Rhythm check-in** и выполните один ручной запуск.
4. Если нужен сайт-инструкции, включите **Настройки → Страницы**, выберите ветку `master` и папку `/public`.

> GitVerse создаёт коммиты по плану самостоятельно. Уведомление в Telegram надёжно отправляет GitHub Actions: runner GitVerse может не иметь доступа к `api.telegram.org`.

## Изменить время запуска

Время запуска задаётся в двух файлах:

- GitHub: [`.github/workflows/daily-checkin.yml`](.github/workflows/daily-checkin.yml)
- GitVerse: [`.gitverse/workflows/daily-checkin.yml`](.gitverse/workflows/daily-checkin.yml)

Найдите строку `cron` и замените её в обоих файлах. Cron всегда использует UTC, а `timeZone` в `rhythm.config.json` определяет, к какой календарной дате отнести коммит.

Примеры для Екатеринбурга (UTC+5):

| Когда запускать | Строка cron |
| --- | --- |
| каждый день в 00:05 | `5 19 * * *` |
| каждый день в 09:00 | `0 4 * * *` |
| пн–пт в 20:30 | `30 15 * * 1-5` |

После изменения сохраните оба файла и сделайте commit + push. С этого момента workflow будет запускаться в новое время.

## Настроить уровень активности

План находится в [`rhythm.config.json`](rhythm.config.json). Workflow запускается каждый день, но число коммитов определяет именно этот файл.

### Как изменить коммиты самому

1. Откройте файл [`rhythm.config.json`](rhythm.config.json).
2. Найдите блок `dateLevels`.
3. Добавьте нужную дату и число от `0` до `15`.
4. Сохраните файл и сделайте обычный commit + push. Новое правило сработает в 00:05 выбранного дня.

Например, этот план создаст 1 коммит 23 сентября, 6 коммитов 24 сентября, 12 — 25 сентября и оставит 26 сентября пустым:

```json
{
  "timeZone": "Asia/Yekaterinburg",
  "activeWeekdays": [1, 2, 3, 4, 5],
  "biweeklySunday": true,
  "defaultLevel": 1,
  "dateLevels": {
    "2026-09-23": 1,
    "2026-09-24": 6,
    "2026-09-25": 12,
    "2026-09-26": 0
  }
}
```

- `0` — пустой день, workflow не делает коммиты;
- `1` — обычный активный день с одним коммитом;
- `2–15` — более активный день: от двух до пятнадцати записей в журнале и столько же коммитов;
- `dateLevels` всегда важнее обычного недельного расписания;
- `activeWeekdays` задаёт обычные дни недели: `0` — воскресенье, `1` — понедельник, …, `6` — суббота;
- `timeZone` меняет часовой пояс. При изменении проверьте cron в workflow: он всегда указан в UTC.

Точный оттенок квадратика рисует сама площадка — GitHub или GitVerse. Rhythm управляет числом запланированных коммитов, но не подменяет правила платформы.

## Как устроено

```text
workflow по расписанию
        ↓
scripts/mark-today.mjs
        ↓
public/data/checkins.json
        ↓
запланированное число коммитов в вашем репозитории
```

## Безопасность

Не добавляйте email, токены или пароли прямо в файлы проекта. Email для автора коммитов хранится в секретах репозитория. Secrets не попадают в исходный код и не видны другим пользователям.
