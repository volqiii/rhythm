Два способа

Поставить за несколько минут

Один и тот же проект работает на обеих площадках. Для авторства коммитов нужны только имя и подтверждённый email в секретах репозитория.

GitHub

Actions
  1. Создайте репозиторий из шаблона.
  2. Разрешите Actions записывать в репозиторий.
  3. Добавьте `COMMIT_AUTHOR_NAME` и `COMMIT_AUTHOR_EMAIL` в Secrets.
  4. Запустите Rhythm check-in один раз.

GitVerse

CI/CD
  1. Создайте публичный репозиторий и загрузите проект.
  2. Добавьте два авторских секрета в настройках.
  3. Откройте CI/CD и запустите Rhythm check-in.
  4. При желании включите Pages из папки `/public`.

Цвет карты активности остаётся решением GitHub или GitVerse. Rhythm задаёт число записей в открытом личном журнале, но точный оттенок всегда зависит от правил площадки.
